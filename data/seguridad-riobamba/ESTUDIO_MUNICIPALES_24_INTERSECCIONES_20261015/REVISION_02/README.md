# Estudio municipal no aplicado

Abrir index.html mediante servidor HTTP para comparar mapas, o COMPARACION_MUNICIPALES_24.png para la imagen estatica. INFORME.md y RESULTADOS.json documentan parametros, catalogos, restricciones y SHA256 de fuentes.

GeoPackage en EPSG:32717; derivados GeoJSON en EPSG:4326. ACTUALES_24 conserva las posiciones actuales. Capas con _PUNTOS son alternativas no aprobadas; _MOVIMIENTOS son desplazamientos rectos; _ENLACES_400M son rutas de la red GIS entre estas24municipales, no visibilidad certificada. Los CSV _PARES_POR_RED incluyen todos los276pares por escenario.

El codigo requiere el proyecto y sus fuentes originales locales; no es un instalador autonomo. No ejecutar sobre datos oficiales sin revision. La publicacion del estudio no modifica las posiciones del visor ni implica aprobar una alternativa.
